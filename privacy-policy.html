5. Security and encryption

5.1 AES-256 encryption

The following data is encrypted with AES-256:

  • Events (simple, multi-day, recurring)
  • Birthdays
  • TodoList tasks
  • Categories (calendar and TodoList)
  • File metadata
  • Password
  • PIN code
  • Trash (all deleted items)
  • Custom colors
  • Settings and preferences

5.2 Multi-method authentication

Three independent configurable methods:

  • Biometrics: fingerprint or face recognition (managed by system)
  • PIN code: 4 to 6 digits, customizable
  • Password: free text, minimum 4 characters

Security features:

  • Independent enable/disable of each method
  • Smooth navigation between methods during authentication
  • Setup wizard on first launch
  • Individual modification of each method in settings
  • Default password detection with prompt to change
  • "Don't remind me" option for default password alert
  • Biometric confirmation for sensitive actions (security disable)

5.3 Encryption key

  • Automatically and locally generated on first use
  • Securely stored via Flutter Secure Storage
  • Never leaves your device
  • Used for all encryption/decryption operations
  • Unique per installation

5.4 Encrypted backups

  • Proprietary format: .scbk files (SafeCalen Backup)
  • AES-256 encryption: with custom password chosen at export
  • Complete content: all events, categories, tasks, colors, trash
  • Metadata: version, export date for compatibility
  • Secure import: password verification and preview before restoration

6. Attachments and files

6.1 File management

When you add attachments:

Photos (camera)

  • A copy is saved in the app's private directory
  • The original remains in your gallery
  • Camera permission requested only when used

Photos (gallery)

  • A local copy is saved in the app
  • The original photo is never modified
  • Gallery permission requested only when used

Documents

  • A copy is saved in the app's private directory
  • Supported formats: PDF, DOC, DOCX, TXT, XLSX, XLS
  • Original files remain intact in your folders
  • Storage permission requested only when used

Links

  • Stored as encrypted text
  • No automatic downloads
  • Opens in external browser when clicked

6.2 File security

Metadata

Names, types, paths → AES-256 encrypted in the database.

Physical files

  • Stored in the app's private directory (sandbox)
  • Protected by OS isolation (Android/iOS)
  • Inaccessible to other apps without root/jailbreak permissions
  • Automatically deleted when uninstalling the app

Important transparency

⚠️ The files themselves (photos, documents) are NOT individually encrypted.

They remain protected by:

  • OS isolation (Android/iOS sandbox)
  • Restricted access to app's internal storage
  • Device lock (PIN/fingerprint/face)
  • OS access permissions

⚠️ On a rooted, jailbroken, or compromised device, these files could theoretically be accessible.

This limitation is due to technical constraints of mobile operating systems and the trade-off between security and performance.

6.3 Attachment management

  • Adding: via event context menu (photos, documents, links)
  • Viewing: open photos in fullscreen with zoom
  • Sharing: ability to share documents via system
  • Deletion: deletes only local copy, never the original
  • Indicators: paperclip icon on events with attachments

6.4 Security recommendations

For optimal security:

  • Enable device locking (PIN, fingerprint, face)
  • Use multiple security methods in SafeCalen (biometrics + PIN/password)
  • Don't share your device with untrusted persons
  • Use encrypted backups regularly
  • Avoid rooted/jailbroken devices for sensitive data
  • Change default password on first launch
  • Keep your OS up to date
