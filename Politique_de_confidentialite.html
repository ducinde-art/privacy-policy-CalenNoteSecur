2. Données stockées localement (jamais transmises)

CalenNoteSecure enregistre uniquement les données nécessaires au fonctionnement local de l'application.

2.1 Calendrier

  • Événements : titre, description, date, heure, catégorie, répétition, rappels
  • Anniversaires : nom, date de naissance, âge, notes, couleur
  • Catégories : nom, couleur, icône
  • Pièces jointes : photos, documents, liens (copie locale uniquement)

2.2 TodoList

  • Tâches : texte, statut, date de création
  • Listes : nom, couleur, icône
  • Organisation des catégories de tâches

2.3 Sécurité

  • Mot de passe (chiffré AES-256)
  • Code PIN (chiffré AES-256)
  • Authentification biométrique (gérée par Android/iOS - biométrie que vous créez via votre téléphone)

2.4 Paramètres

  • Thème (clair/sombre/système)
  • Langue (français/anglais)
  • Préférences d'affichage
  • Paramètres de notifications

2.5 Corbeille

  • Éléments supprimés temporairement
  • Suppression définitive uniquement manuelle

3. Données que nous ne collectons JAMAIS

Aucune donnée personnelle collectée, envoyée ni stockée, y compris :

  • Nom complet
  • Adresse email, téléphone
  • Contacts
  • Localisation GPS
  • Adresse IP, données réseau
  • Historique de navigation, cookies
  • Informations bancaires
  • Identifiants publicitaires
  • Données de l'appareil
  • Photos/documents externes (hors fichiers que vous choisissez d'ajouter)

Aucune donnée ne quitte votre appareil.

  • Gérer les anniversaires

TodoList

Personnalisation

  • Thème

Sauvegarde

  • Export / import de sauvegardes chiffrées

5. Sécurité et chiffrement

5.1 Chiffrement AES-256

Les données suivantes sont chiffrées avec AES-256 :

  • Événements
  • Anniversaires
  • Tâches
  • Catégories
  • Métadonnées des fichiers
  • Mot de passe & PIN
  • Corbeille

5.2 Authentification

  • Biométrie (empreinte digitale, reconnaissance faciale)
  • Code PIN (4 à 6 chiffres)
  • Mot de passe personnalisable

Tous les modes sont optionnels et indépendants.

5.3 Clé de chiffrement

  • Générée automatiquement et localement
  • Stockée de manière sécurisée sur votre appareil
  • Ne quitte jamais votre appareil

6. Pièces jointes et fichiers

6.1 Gestion des fichiers

Lorsque vous ajoutez des pièces jointes :

Photos (appareil photo)

  • Une copie est enregistrée dans le répertoire privé de l'application
  • L'original reste dans votre galerie

Photos (galerie)

  • Une copie est enregistrée localement
  • La photo originale n'est jamais modifiée

Documents

  • Une copie est enregistrée dans le répertoire privé de l'application
  • Les fichiers originaux restent intacts dans vos dossiers

Liens

  • Stockés sous forme de texte
  • Aucun téléchargement automatique

6.2 Sécurité des fichiers

Métadonnées

Noms, types, chemins → chiffrés AES-256 dans la base de données.

Fichiers

  • Stockés dans le répertoire privé de l'application
  • Protégés par la sandbox Android/iOS
  • Inaccessibles aux autres applications

Transparence

⚠️ Les fichiers eux-mêmes (photos, documents) ne sont pas chiffrés.

Ils restent cependant protégés par :

  • L'isolation du système d'exploitation
  • L'accès restreint au stockage interne
  • Le verrouillage de l'appareil

⚠️ Sur un appareil rooté ou compromis, ils pourraient être lisibles.

6.3 Suppression

Supprimer une pièce jointe supprime uniquement la copie locale.

Vos fichiers originaux dans la galerie/dossiers restent intacts.

6.4 Recommandations

Pour une sécurité optimale :

  • Activez le verrouillage de votre appareil (PIN, empreinte, visage)
  • Ne partagez pas votre appareil avec des personnes non fiables
  • Utilisez les sauvegardes chiffrées régulièrement
  • Évitez les appareils rootés/jailbreakés
