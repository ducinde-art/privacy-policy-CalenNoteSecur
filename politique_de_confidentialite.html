2. Données stockées localement (jamais transmises)

SafeCalen enregistre uniquement les données nécessaires au fonctionnement local de l'application.

2.1 Calendrier

  • Événements : titre, description, date, heure, catégorie
  • Événements multi-jours : date de début, date de fin
  • Répétitions : quotidienne, hebdomadaire, mensuelle, dernier jour du mois, annuelle, personnalisée (tous les X jours)
  • Suppression sélective : cette occurrence, toutes les occurrences, occurrences futures, occurrences passées
  • Événements journée entière : sans heure spécifique
  • Anniversaires : nom, date de naissance, année de naissance (pour calcul automatique de l'âge), notes, couleur personnalisée
  • Catégories : nom, couleur personnalisable, icône
  • Rappels : 15 minutes, 1 heure, 1 jour avant l'événement
  • Planification des notifications : durée configurable (jours, semaines, mois) avec aperçu du nombre de notifications
  • Pièces jointes : photos, documents, liens (copie locale uniquement)

2.2 TodoList

  • Tâches : texte, statut de complétion, date de création
  • Listes personnalisées : nom, couleur, icône parmi 60+ icônes disponibles
  • Organisation : déplacement par glisser-déposer entre listes avec retour haptique
  • Statistiques : compteurs de tâches (total, à faire, complétées) affichables/masquables
  • Synchronisation calendrier : option d'ajouter des tâches au calendrier avec préservation de l'icône et couleur d'origine

2.3 Sécurité

  • Mot de passe : chiffré AES-256, configurable indépendamment
  • Code PIN : chiffré AES-256, 4 à 6 chiffres, configurable indépendamment
  • Authentification biométrique : empreinte digitale ou reconnaissance faciale (gérée par Android/iOS), configurable indépendamment
  • Configuration initiale : assistant de configuration au premier lancement pour choisir les méthodes de sécurité
  • Multi-méthodes : possibilité d'activer plusieurs méthodes simultanément avec navigation entre elles

2.4 Paramètres

  • Thème : clair, sombre ou automatique (suit le système)
  • Langue : français ou anglais
  • Préférences d'affichage : statistiques TodoList, dates de création des tâches
  • Filtres agenda : période à venir (demain, semaine, 2 semaines, mois, tout)
  • Paramètres de notifications : activation/désactivation des rappels

2.5 Corbeille

  • Éléments supprimés : événements, anniversaires, tâches, catégories TodoList
  • Métadonnées : type, titre, description, date de suppression
  • Restauration : possibilité de restaurer les éléments supprimés
  • Suppression définitive : uniquement manuelle, élément par élément ou vidage complet

2.6 Cache et synchronisation

  • Gestionnaire de cache unifié : DataCacheManager avec pattern Singleton
  • Synchronisation temps réel : système de listeners pour mise à jour automatique entre toutes les pages
  • Données en mémoire : événements, catégories, tâches, couleurs personnalisées
  • Chargement au démarrage : pré-chargement de toutes les données pour performances optimales

2.7 Couleurs personnalisées

  • Palette par défaut : 25+ couleurs prédéfinies pour catégories et anniversaires
  • Couleurs personnalisées : création illimitée via sélecteur de couleurs avancé
  • Sauvegarde : stockage sécurisé des couleurs personnalisées avec identifiant unique
  • Gestion : suppression des couleurs personnalisées non utilisées

5. Sécurité et chiffrement

5.1 Chiffrement AES-256

Les données suivantes sont chiffrées avec AES-256 :

  • Événements (simples, multi-jours, répétitifs)
  • Anniversaires
  • Tâches TodoList
  • Catégories (calendrier et TodoList)
  • Métadonnées des fichiers
  • Mot de passe
  • Code PIN
  • Corbeille (tous les éléments supprimés)
  • Couleurs personnalisées
  • Paramètres et préférences

5.2 Authentification multi-méthodes

Trois méthodes indépendantes configurables :

  • Biométrie : empreinte digitale ou reconnaissance faciale (gérée par le système)
  • Code PIN : 4 à 6 chiffres, personnalisable
  • Mot de passe : texte libre, minimum 4 caractères

Fonctionnalités de sécurité :

  • Activation/désactivation indépendante de chaque méthode
  • Navigation fluide entre les méthodes lors de l'authentification
  • Assistant de configuration au premier lancement
  • Modification individuelle de chaque méthode dans les paramètres
  • Détection du mot de passe par défaut avec invitation à le changer
  • Option "Ne plus me rappeler" pour l'alerte de mot de passe par défaut
  • Confirmation biométrique pour les actions sensibles (désactivation de sécurité)

5.3 Clé de chiffrement

  • Générée automatiquement et localement lors de la première utilisation
  • Stockée de manière sécurisée via Flutter Secure Storage
  • Ne quitte jamais votre appareil
  • Utilisée pour toutes les opérations de chiffrement/déchiffrement
  • Unique par installation

5.4 Sauvegardes chiffrées

  • Format propriétaire : fichiers .scbk (SafeCalen Backup)
  • Chiffrement AES-256 : avec mot de passe personnalisé choisi à l'export
  • Contenu complet : tous les événements, catégories, tâches, couleurs, corbeille
  • Métadonnées : version, date d'export pour compatibilité
  • Import sécurisé : vérification du mot de passe et aperçu avant restauration

6. Pièces jointes et fichiers

6.1 Gestion des fichiers

Lorsque vous ajoutez des pièces jointes :

Photos (appareil photo)

  • Une copie est enregistrée dans le répertoire privé de l'application
  • L'original reste dans votre galerie
  • Permission caméra demandée uniquement au moment de l'utilisation

Photos (galerie)

  • Une copie est enregistrée localement dans l'application
  • La photo originale n'est jamais modifiée
  • Permission galerie demandée uniquement au moment de l'utilisation

Documents

  • Une copie est enregistrée dans le répertoire privé de l'application
  • Formats supportés : PDF, DOC, DOCX, TXT, XLSX, XLS
  • Les fichiers originaux restent intacts dans vos dossiers
  • Permission stockage demandée uniquement au moment de l'utilisation

Liens

  • Stockés sous forme de texte chiffré
  • Aucun téléchargement automatique
  • Ouverture dans le navigateur externe lors du clic

6.2 Sécurité des fichiers

Métadonnées

Noms, types, chemins → chiffrés AES-256 dans la base de données.

Fichiers physiques

  • Stockés dans le répertoire privé de l'application (sandbox)
  • Protégés par l'isolation du système d'exploitation (Android/iOS)
  • Inaccessibles aux autres applications sans permissions root/jailbreak
  • Supprimés automatiquement lors de la désinstallation de l'application

Transparence importante

⚠️ Les fichiers eux-mêmes (photos, documents) ne sont PAS chiffrés individuellement.

Ils restent cependant protégés par :

  • L'isolation du système d'exploitation (sandbox Android/iOS)
  • L'accès restreint au stockage interne de l'application
  • Le verrouillage de l'appareil (PIN/empreinte/visage)
  • Les permissions d'accès du système d'exploitation

⚠️ Sur un appareil rooté, jailbreaké ou compromis, ces fichiers pourraient théoriquement être accessibles.

Cette limitation est due aux contraintes techniques des systèmes d'exploitation mobiles et au compromis entre sécurité et performances.

6.3 Gestion des pièces jointes

  • Ajout : via menu contextuel des événements (photos, documents, liens)
  • Visualisation : ouverture des photos en plein écran avec zoom
  • Partage : possibilité de partager les documents via le système
  • Suppression : supprime uniquement la copie locale, jamais l'original
  • Indicateurs : icône de trombone sur les événements avec pièces jointes

6.4 Recommandations de sécurité

Pour une sécurité optimale :

  • Activez le verrouillage de votre appareil (PIN, empreinte, visage)
  • Utilisez plusieurs méthodes de sécurité dans SafeCalen (biométrie + PIN/mot de passe)
  • Ne partagez pas votre appareil avec des personnes non fiables
  • Utilisez les sauvegardes chiffrées régulièrement
  • Évitez les appareils rootés/jailbreakés pour des données sensibles
  • Changez le mot de passe par défaut dès le premier lancement
  • Gardez votre système d'exploitation à jour

14. Conformité RGPD

SafeCalen respecte et dépasse les exigences du RGPD (Règlement Général sur la Protection des Données) :

14.1 Principes RGPD appliqués

  • Transparence : Cette politique vous informe clairement de toutes nos pratiques
  • Minimisation des données : Nous collectons uniquement les données strictement nécessaires au fonctionnement
  • Limitation de la finalité : Les données servent uniquement aux fonctionnalités décrites
  • Exactitude : Vous contrôlez et modifiez vos données à tout moment
  • Limitation de la conservation : Les données sont conservées tant que vous utilisez l'application
  • Intégrité et confidentialité : Chiffrement AES-256 et stockage sécurisé
  • Responsabilité : Nous documentons toutes nos pratiques de protection des données

14.2 Droits RGPD garantis

  • Droit d'accès : Vous voyez toutes vos données dans l'application
  • Droit de rectification : Vous modifiez vos données à tout moment
  • Droit à l'effacement : Vous supprimez vos données partiellement ou totalement
  • Droit à la portabilité : Vous exportez vos données dans un format structuré (JSON chiffré)
  • Droit d'opposition : Architecture locale sans traitement imposé
  • Droit à la limitation du traitement : Vous contrôlez toutes les fonctionnalités

14.3 Architecture "Privacy by Design"

SafeCalen est conçu dès l'origine pour garantir votre vie privée :

  • Aucune connexion serveur (pas de backend)
  • Aucune collecte de données (pas de base de données externe)
  • Stockage 100% local et chiffré
  • Vous êtes le seul responsable du traitement de vos données
  • Aucun sous-traitant (pas de services tiers)
  • Aucun transfert international de données
  • Aucun profilage ou décision automatisée

14.4 Absence d'obligations RGPD spécifiques

Du fait de notre architecture 100% locale, certaines obligations RGPD ne s'appliquent pas :

  • Pas de DPO (Délégué à la Protection des Données) : Aucun traitement à grande échelle
  • Pas d'AIPD (Analyse d'Impact) : Aucun risque pour les droits et libertés
  • Pas de registre des traitements : Aucun traitement de données personnelles
  • Pas de notification de violation : Aucune base de données à pirater
  • Pas de consentement requis : Vous contrôlez directement vos données

En utilisant SafeCalen, vous bénéficiez du plus haut niveau de protection de la vie privée possible.

Vos données ne quittent jamais votre appareil et restent sous votre contrôle exclusif.
