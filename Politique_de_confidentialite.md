    Thème (clair/sombre/système)
    Langue (français/anglais)
    Langue

    Éléments supprimés temporairement

6. Pièces jointes et fichiers
   
  6.1 Gestion des fichiers
  
    Lorsque vous ajoutez des pièces jointes :
   
    Photos (appareil photo)
    Une copie est enregistrée dans le répertoire privé de l’application.
    L’original reste dans votre galerie.
   
    Photos (galerie)
    Une copie est enregistrée localement.
    La photo originale n’est jamais modifiée.
   
    Documents
    Une copie est enregistrée dans le répertoire privé de l’application.
    Les fichiers originaux restent intacts dans vos dossiers.
   
    Liens
    Stockés sous forme de texte.
    Aucun téléchargement automatique.

  6.2 Sécurité des fichiers
  
    Métadonnées
    Noms, types, chemins → chiffrés AES-256 dans la base de données.
    
    Fichiers
    Stockés dans le répertoire privé de l’application
    Protégés par la sandbox Android/iOS
    Inaccessibles aux autres applications
    Transparence
  
      ⚠️ Les fichiers eux-mêmes (photos, documents) ne sont pas chiffrés.
  
    Ils restent cependant protégés par :
    l’isolation du système d’exploitation
    l’accès restreint au stockage interne
    le verrouillage de l’appareil
  
      ⚠️ Sur un appareil rooté ou compromis, ils pourraient être lisibles.

  6.3 Suppression
  
    Supprimer une pièce jointe supprime uniquement la copie locale.
    Vos fichiers originaux dans la galerie/dossiers restent intacts.

  6.4 Recommandations
  
    Pour une sécurité optimale :
    Activez le verrouillage de votre appareil (PIN, empreinte, visage)
    Ne partagez pas votre appareil
    Utilisez les sauvegardes chiffrées
    Évitez les appareils rootés/jailbreakés
